# juanseb8778.github.io

Página personal de **Juan Sebastián Ángel Ramírez**, desarrollador web full stack.

🔗 **https://juanseb8778.github.io**

- Hecha con **Angular** (componentes standalone y signals).
- Bilingüe: español e inglés, con el idioma guardado en el navegador.
- Se publica sola en **GitHub Pages** con GitHub Actions en cada push a `main`.

## Desarrollo

```bash
npm install
npx ng serve      # http://localhost:4200
npx ng build      # genera dist/portfolio/browser
```

El contenido de la página (textos, experiencia y proyectos) está en `src/app/content.ts`.
